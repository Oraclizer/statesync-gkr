# Replay metadata

This tree is generated by `cargo creusot` and holds the proof-replay records
that connect named Rust functions to their Creusot specifications, one
`proof.json` per proved obligation plus the Why3 session files. The workspace
configuration that drives it is `why3find.json` at the repository root.

These records are tool inputs for replaying the contract proofs. They are not
a substitute for reading the named source, the stated assumptions, and the
tool output; the boundaries are described in
[FORMAL_VERIFICATION.md](../FORMAL_VERIFICATION.md).

No hosted workflow re-runs Creusot or Why3, so unlike the Isabelle sessions
this tree is not rebuilt on every push. It is a recorded result, and replaying
it needs the Creusot toolchain and the solvers named in `why3find.json`
installed locally. Read it as evidence of what the contract proofs established
when they were run, checked against the named source, rather than as a
continuously enforced gate.
