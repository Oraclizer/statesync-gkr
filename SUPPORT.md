# Support

This public repository provides best-effort community support. Commercial
licensing for production use is arranged with Oraclizer Labs, Inc. through
[oraclizer.io](https://oraclizer.io). Security reports follow
[SECURITY.md](SECURITY.md).

## Public issues

Use public issues for reproducible defects, documentation errors, and focused
design proposals. Include the exact revision, operating system, tool versions,
commands, expected behavior, observed behavior, and a minimal reproduction.

Do not use a public issue for an undisclosed vulnerability. Follow
[SECURITY.md](SECURITY.md) instead.

## Supported questions

Maintainer responses may cover the repository source, documented build and test
commands, public vectors, formal sessions, release verifier, and claim
boundaries. Questions that trace an acceptance check to its selected Rust
contract, forward theorem or recorded open obligation can use the
[refinement review map](docs/refinement.md).

The repository does not provide deployment operation, key management, incident
response, legal or regulatory advice, performance guarantees, integration
service levels, or support for arbitrary forks.

## What to expect

Issues are triaged in batches. If a thread has gone quiet, a comment on it is
welcome and is the fastest way to get it picked back up.

Reproducible defects and concrete documentation errors are handled first.
Broad questions and large proposals may take longer, or may be answered with a
pointer to the relevant boundary document rather than a full discussion.

Community support in this repository is best-effort. Production support is
arranged with Oraclizer Labs, Inc. under a commercial license.
